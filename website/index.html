Ten tools, one window

Each tool covers the everyday work of a familiar professional app. They share one interface, one set of shortcuts and one AI assistant, and they hand work to each other.

AI without API bills

Use the AI you already pay for

  • Ultima starts the official command-line tool you installed and signed in to — Claude Code, Codex, Antigravity CLI, GitHub Copilot and others — exactly as you would in a terminal.
  • Your requests count against your own plan. Ultima never sees, stores or sends your password or tokens, and it removes API-key variables so nothing is billed per token.
  • No subscription? Run a free model on your own computer with Ollama or LM Studio. It works offline.
  • The assistant edits your document directly: describe the change, review the steps, apply. Every tool has one.

Each AI tool runs under its vendor's terms. Ultima shows those terms before you turn a tool on. Anthropic's terms do not clearly cover third-party apps that start Claude Code, so please read them before enabling it.

Up and running in three steps

The editors work without any AI. Connect one when you want the assistant.

1

Install Ultima

Download the file for your system above and open it. On first launch you land on the Home screen with every tool.

2

Install and sign in to an AI tool

Claude Pro or Max
curl -fsSL https://claude.ai/install.sh | bash
claude auth login
ChatGPT Plus, Pro or Business
npm install -g @openai/codex
codex login
Google AI Pro or Ultra — Antigravity CLI
curl -fsSL https://antigravity.google/cli/install.sh | bash
agy
GitHub Copilot plan
npm install -g @github/copilot
copilot login
Free, runs offline on your computer
curl -fsSL https://ollama.com/install.sh | sh
ollama pull gemma3
3

Turn it on in Ultima

Open Settings → AI connections. Ultima finds the tools on your computer. Switch one on, press Test, and open the AI panel in any tool with Ctrl/⌘ + J.
